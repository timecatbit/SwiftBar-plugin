# 更新记录

## 5.1.1 · 2026-11-05

- 面板与侧栏空间充足时禁止双指滚动和回弹；内容超出高度时才允许滚动。

- 折叠改为按模块独立保存，可同时展开多个；迁移旧版展开项，隐藏或暂时关闭折叠不会清除状态。
- 修复保存回执早于数据快照时状态回退的问题，快速连续点击按最终顺序显示。
- 后台检查期间菜单动作排队执行，不再忽略点击；折叠标题与菜单行明确接受首次点击，刷新避开鼠标按下期间。

## 5.1.0 · 2026-11-05

- 自动检测加入悬停说明；先扫描再确认，预览将启用/取消的模块，明确覆盖当前选择。默认取消，确认后才替换，取消保留原设置。
- 主页模块新增“允许折叠”：客户端标题保留费用、Token 和状态，点击展开一项明细，其他项自动收起；展开状态随刷新保留。关闭开关恢复完整展示，Summary 统计不受影响。

## 5.0.2 · 2026-11-05

- 右键星星新增“自动检测”，一键发现并补选已安装客户端和已配置 API 模块。

## 5.0.1 · 2026-11-05

- 首次安装自动选择检测到的客户端记录与 API 资源；升级保留已有选择，并可手动检测补选。

- 打开账户额度、API 余额、Komari 和应用更新侧栏时立即检查对应来源，短时间内重复悬停去重。
- 启用账户模块立即刷新；后台数据完成后主动更新面板，不再等下个 30 秒周期。
- 保持侧栏展开，重绘不会重复发起检查。

## 5.0.0 — 2026-11-05

- 模块管理收窄至 280pt，修正勾选图标；支持连续多选与 80ms 悬停侧栏。
- 加入 WorkBuddy、Gemini CLI 本机用量，Grok API 余额与 MiniMax 套餐额度；OpenCode 可独立读取。

- 主页模块可持续勾选并保存；右键菜单精简为模块入口及 SwiftBar 自身管理。
- 原生玻璃材质、深浅色和降低透明度适配；侧栏悬停缩短到 80ms。
- 新增 Codex、OpenCode、DeepSeek Harness 本机用量及 ChatGPT 登录额度模块。
- DeepSeek 余额可独立配置，新增客户端不依赖 OpenCodex。
- 路径按用户环境检测并可自定义，安装后独立于源码仓库运行。
- 用量增量索引、重复记录处理、未计价/不可用状态与原生文本降级。
