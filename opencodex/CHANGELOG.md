# 更新记录

## 5.0.0 — 2026-11-05

- 模块管理收窄至 280pt，修正勾选图标；支持连续多选与 80ms 悬停侧栏。
- 加入 WorkBuddy、Gemini CLI 本机用量，Grok API 余额与 MiniMax 套餐额度；OpenCode 可独立读取。

- 主页模块可持续勾选并保存；右键菜单精简为模块入口及 SwiftBar 自身管理。
- 原生玻璃材质、深浅色和降低透明度适配；侧栏悬停缩短到 80ms。
- 新增 Codex、OpenCode、DeepSeek Harness 本机用量及 ChatGPT 登录额度模块。
- DeepSeek 余额可独立配置，新增客户端不依赖 OpenCodex。
- 路径按用户环境检测并可自定义，安装后独立于源码仓库运行。
- 用量增量索引、重复记录处理、未计价/不可用状态与原生文本降级。
